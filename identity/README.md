# identity/

Identity files that OpenClaw bootstraps and we customize. Deployed to `~/.openclaw/workspace/` on the VPS.

| File | Authored in | Purpose |
|------|------|---------|
| `AGENTS.md` | Phase 2 (drafted) → Phase 3 (final) | Safety constitution. Inherited by all subagents. SOURCE OF SECURITY. |
| `SOUL.md` | Phase 3 (initial) → Phase 4 (`soul-audit` refines) | Agent voice. Terse, direct, no flattery. |
| `USER.md` | Phase 3 | Hand-written context about the user. |
| `TOOLS.md` | Phase 3 (auto-generated by OpenClaw) + custom safety notes appended | Per-tool capabilities and safety annotations. |
| `IDENTITY.md` | Phase 3 | Auto-generated; light customization. |
| `HEARTBEAT.md` | Phase 4 (empty stub) → Phase 5 (drafting from observations) → Phase 6 (active) | Hourly checklist. Stays empty until Stage 2 of heartbeat rollout. |
| `ACCESS_POLICY.md` | Phase 4 (`soul-audit` generates) | 4-tier data sensitivity policy. |
| `RESOLVER.md` | Phase 4 (auto from skill installs) | Intent → skill mapping. |
| `MEMORY.md` | Auto-managed | Agent-managed organic memory. NOT inherited by subagents (per OpenClaw spec). |

Phase 0 status: empty (placeholders authored in later phases).
